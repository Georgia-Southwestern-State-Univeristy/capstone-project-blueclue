RAG Pipeline · src/rag_pipeline.py
Step 1 — Embed query
ada-002 (1536-dim) · MiniLM fallback (384-dim)
Encodes user message into vector
Step 2 — Category-scoped vector search
WHERE category = [ML category]
ORDER BY embedding <=> query_vector LIMIT k
Cosine similarity via pgvector ivfflat index
Step 3 — Prompt Builder
System prompt includes ML result block:
category, priority, confidence, estimated_hours
KB article snippets appended as grounded context
Conversation history (last N turns) included
Step 4 — LLM Completion
gpt-3.5-turbo / gpt-4o-mini
Max retries 2 · token usage logged
Cost tracked per call
How AI Uses ML Output
Category-aware KB retrieval
ML category narrows KB search
"Hardware" ticket only searches hardware articles
Priority context in response
LLM told ticket priority is "Critical"
Response tone and urgency shaped accordingly
Resolution time reference
LLM can reference estimated_hours in reply
"This typically takes about X hours to resolve"
Confidence-gated depth
Low ML confidence → broader KB search
High confidence → focused, category-specific answer
